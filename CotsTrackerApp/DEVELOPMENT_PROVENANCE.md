# COTS Tracker development record

**Source import date:** November 5, 2026

**Project owner/applicant identified by the project maintainer:** SLSU-BONTOC Digital Technology

**Repository:** `https://github.com/rextold/dap-agtracker`

The Flutter application source was added to this repository as a dated source
snapshot. Earlier development occurred in the local `CotsTrackerApp` directory,
which was previously excluded from Git. This commit records the source as it
exists now; it does not invent or backdate a step-by-step development history.

The project maintainer directed the app's scope, production domain, branding,
SLSU–DOST partnership presentation, location catalog, offline reporting, and
Google Play release work. OpenAI Codex assisted with code, design adaptation,
testing, documentation, and build preparation. This assistance is disclosed
openly. Any human authorship, institutional ownership, employment or assignment
rights, and permission to use partner names and logos should be supported by
the relevant project records and agreements.

Included source and evidence:

- `lib/`, `test/`, `assets/`, and Flutter platform project files contain the
  application implementation and tests.
- `pubspec.yaml` and `pubspec.lock` record direct and resolved dependencies.
- `store_listing/` contains the Play listing graphics prepared for this app.
- `assets/images/BRANDING.md` records the image source and AI generation prompt.
- `third_party/materialize/` contains the upstream MIT license and source
  attribution for the visual reference downloaded for this project.
- The repository commit and signed Android App Bundle can be compared with the
  source snapshot and build instructions in `PRODUCTION_READINESS.md`.

The upload keystore, passwords, local configuration, generated build output,
and private credentials are intentionally excluded from the repository. The
upload key must be retained securely by the project owner to issue future
updates under the same Google Play app identity.
